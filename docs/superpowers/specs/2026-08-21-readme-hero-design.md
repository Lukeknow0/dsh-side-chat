## Goal

Create one English-language project introduction image for both `README.md` and `README.zh.md`. It should borrow the clear product-showcase structure of the supplied `dsh-nested-followups` reference while remaining unmistakably `dsh-side-chat`.

## Deliverable

- PNG, 2400 × 1350 px
- Filename: `dsh-side-chat-readme-hero-en.png`
- Intended placement: near the top of both README files

## Input roles

- Supplied nested-followups graphic: composition reference only — left narrative, right product surface, bottom capability cards.

## Composition

Use a warm off-white canvas with generous breathing room. The upper two-thirds use an asymmetrical 34/66 split:

- Left: small product-category label, large project name, short product description, campaign statement, and the rail symbol.
- Right: the real installed-state screenshot inside a polished, softly elevated product frame with only a mild perspective angle.
- Bottom: five equal capability cards in one row, visually quieter than the title and product frame.

Use restrained mint rail lines sweeping through the lower edge to connect the cards and product frame. Coral appears only as a tiny punctuation/accent point. Do not use generic purple/blue AI gradients.
