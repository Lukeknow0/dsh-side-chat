# 侧聊精简与原生多标签设计

状态：用户已选择「每条侧聊是独立标签页」，并要求先保存修改前 Git 快照。快照为 `6f58ae4`。

## 用户可见行为

- 顶部使用 DSH 原生标签条；通过其加号及「新建侧聊」指南打开独立空白侧聊页。
- 一条侧聊对应一个原生标签，不在聊天面板内重复显示标题、新建按钮或第二层历史标签。
- 删除主会话/侧聊 ID 展示、复制按钮、复制反馈、重命名及归档入口和面板内对应处理逻辑。内部会话标识和 Host 兼容接口保留，不删除已有会话、历史或草稿。
- 新页第一次发送才创建子会话；打开空白标签不创建 Host Session。失败重试复用已创建的子会话及相同 prompt request ID。
- 成功发送后将空白页导航到稳定的插件自有会话地址；再次打开同一历史会话由宿主揭示已有标签，不重复打开相同会话。
- 空白页可列出当前主会话已有侧聊，以便重开已关闭标签；该列表只在空白页出现，不是聊天顶部的第二层导航。
- 原生标签标题使用现有会话名称；无名称时用本地首条问题摘要或稳定编号区分。不调用重命名 API。
- 关闭标签只释放 UI/轮询，不归档、删除或取消 Host 会话。主会话切换不串会话、草稿、模型、审批或问题。
- 保留输入框已有模型、权限与设置入口；只移除设置区内的会话管理功能，不改输入框内部样式和菜单。

## 实现边界

宿主契约以项目安装的 `@deepseek-ai/dsh-client-ui-sidebar-right@0.2.0-rc.2` 类型和实现为依据：`multiple: true`、插件自有资源地址、`useTabInfo`、`tab.actions.openResource` 和标题 slot。沿用独立 `dsh-sidechat` kind 与 `dsh-sidechat:conversation` implementation ID；不占用或改动 better-sidebar 的注册与源文件。

- native-tab：静态类型声明、地址构造/解析。
- thread state：持久化原生空白页到 child 的绑定、首条标题与草稿；协调同页创建的并发请求。
- SideChatPanel：展示一条由原生标签身份确定的侧聊，不使用全局 selected child 驱动多个新标签。
- 标题 slot：读取同一绑定与状态，以原生标签承载标题。

保留旧版单页地址的恢复路径；客户端列表仍验证当前 parent 下的 child，不将别的 parent 的地址当作当前会话。隐藏面板停止轮询，关闭后恢复历史仍可发送。
